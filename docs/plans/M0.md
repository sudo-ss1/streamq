# M0 — Scaffolding (plan)

SPEC §9 M0: go.mod, Makefile, buf config, `.golangci.yml`, GitHub Actions (lint, test -race,
build), empty binaries, `docs/DECISIONS.md`. Acceptance: `make lint test build` passes.

## Files
- `go.mod` — module `github.com/sudo-ss1/streamq`, `go 1.26`.
- `Makefile` — `tools` (pinned buf, golangci-lint, protoc-gen-go, protoc-gen-go-grpc into
  `.tools/bin`, one stamp file per tool+version), `gen`, `build`, `test` (`-race -count=1`),
  `test-int`, `lint`, `fmt`, `clean`; `fuzz`/`bench`/`cluster-up`/`cluster-down`/`chaos` are stubs
  naming the milestone that implements them.
- `buf.yaml`, `buf.gen.yaml` — module `api`, managed `go_package_prefix`, output to `gen/` (D1).
- `.golangci.yml` (v2) — standard set + contextcheck, copyloopvar, errorlint, forbidigo,
  gochecknoglobals, gochecknoinits, gocritic, gosec, misspell, noctx, nolintlint, revive,
  sloglint, testifylint, thelper, unconvert, unparam; gofmt + goimports; `gen/` excluded.
- `.github/workflows/ci.yml` — lint (golangci-lint-action pinned to the Makefile version, plus a
  `make gen` drift check), test (`make test`), build (`make build`).
- `cmd/streamq-broker/main.go`, `cmd/streamqctl/main.go` — empty binaries that log via slog.
- `docs/DECISIONS.md` (D1, D2), `docs/PROGRESS_LOG.md`, `.gitignore`.

## Tests
None beyond the toolchain itself; acceptance is `make lint test build`. Lint rules were checked
against a throwaway file with a global var, `init()`, `fmt.Println` and undocumented exports.
